# Projeto: Design e Desenvolvimento de Interface

## **Fase 1: Planejamento**

### 1. Introdução ao Projeto

- Objetivo: Criar um design no Figma e implementá-lo em HTML e CSS.
- Importância: Alinhar design e desenvolvimento para criar interfaces funcionais e atraentes.

### 2. Definição do Tema

- Sugestões de temas (ou liberdade para os alunos escolherem):
  - Site de portfólio
  - Landing page de produto
  - Página de cadastro
- Cada grupo deve documentar:
  - **Ideia principal**: Nome da ferramenta/site.
  - **Público-alvo**.
  - **Objetivos da interface**.

### 3. Entrega Inicial

- Documento simples (1 página) contendo:
  - Nome do projeto.
  - Objetivo da interface.
  - Público-alvo.

## **Fase 2: Design no Figma**

### 1. Exploração de Ideias

- Pesquisa de referências de design.
- Planejamento inicial dos elementos principais.
- Estruturação da ideia a ser desenvolvida.

### 2. Estruturação do Design

- Abordar:
  - **Wireframes**: Esboços básicos para planejar os elementos.
  - **Hierarquia visual**: Fontes, cores e espaçamentos para destacar informações.
  - **Responsividade**: Versões para desktop e mobile (media-queries).

### 3. Requisitos do Design

Cada design deve incluir:

- **Cabeçalho**: Logotipo e menu de navegação.
- **Seção principal**: Banner ou chamada de ação.
- **Duas seções adicionais**: Ex.: lista de produtos, formulário de contato.
- **Rodapé**: Informações básicas.

### 4. Entrega do Design

- Compartilhar o link do projeto no Figma com descrição dos elementos principais.

## **Fase 3: Desenvolvimento em HTML e CSS**

### 1. Estruturação HTML

- Divisão em seções:
  - **Cabeçalho** e menu de navegação.
  - **Conteúdos principais**: Banner e seções adicionais.
  - **Rodapé**

### 2. Estilização com CSS

- **Cores e fontes**: Correspondentes ao design.
- **Box model**: Espaçamentos e bordas.
<!-- - **Layout**: Uso de Flexbox ou CSS Grid. -->

### 3. Requisitos Técnicos

- **Responsividade**:
  - Desktop: Largura mínima de 1280px.
  - Mobile: Largura mínima de 375px.
- Utilizar CSS externo (arquivo separado).
- Implementar ao menos:
  - Uma animação ou transição CSS.

### 4. Entrega do Código

- Repositório no GitHub **OU** arquivos compactados (ZIP).

## **Fase 4: Apresentação Final (1 aula)**

### 1. Demonstração

Cada grupo deve apresentar:

- Link para o design no Figma.
- Versão final do site em HTML e CSS.
- Justificativa para escolhas de design e funcionalidades.

### 2. Avaliação

Critérios de avaliação:

- **Design**: Estética, organização e aderência ao tema.
- **Código**: Estrutura semântica, boas práticas e responsividade.
- **Apresentação**: Clareza e objetividade ao explicar o projeto.
