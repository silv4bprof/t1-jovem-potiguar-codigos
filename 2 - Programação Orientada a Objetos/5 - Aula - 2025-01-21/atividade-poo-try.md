# Questões sobre `try` e `except` no Python

## Nível Fácil

1. **Simples tratamento de erro:**  
   Crie um programa que peça ao usuário um número e exiba o dobro dele. Use `try` e `except` para tratar o caso em que o usuário digita algo que não seja um número.

2. **Erro ao acessar índice inexistente:**  
   Escreva um programa que tenha a lista `numeros = [10, 20, 30]`. Peça ao usuário um índice e exiba o número correspondente. Use `try` e `except` para lidar com erros de índices fora do alcance.

3. **Divisão por zero:**  
   Solicite ao usuário dois números e exiba o resultado da divisão do primeiro pelo segundo. Use `try` e `except` para tratar o caso de divisão por zero.

4. **Conversão de string para inteiro:**  
   Crie um programa que peça ao usuário para digitar sua idade. Use `try` e `except` para exibir uma mensagem apropriada caso o valor digitado não seja um número válido.

5. **Soma com entradas inválidas:**  
   Solicite ao usuário dois números e exiba a soma deles. Use `try` e `except` para tratar casos em que o usuário digite algo que não seja um número.

---

## Nível Intermediário

6. **Erro em operações com lista:**  
   Escreva um programa que peça ao usuário um índice para remover um item da lista `frutas = ["maçã", "banana", "laranja"]`. Use `try` e `except` para tratar os erros caso o índice fornecido seja inválido.

7. **Tratamento de múltiplos erros:**  
   Peça ao usuário dois números para realizar uma divisão. Use `try` e `except` para tratar tanto o erro de divisão por zero quanto o erro de digitar algo que não seja um número.

8. **Erro em cálculo com entrada do usuário:**  
   Solicite que o usuário digite dois números e calcule a raiz quadrada do produto deles. Use `try` e `except` para tratar erros, como entradas inválidas ou resultado negativo (use a biblioteca `math`).

9. **Lidando com entradas inválidas para cálculos:**  
   Solicite ao usuário que insira uma lista de números separados por vírgulas e calcule a soma deles. Use `try` e `except` para tratar erros como a entrada de valores não numéricos.

10. **Erro com funções personalizadas:**  
    Crie uma função que receba dois números e calcule o quociente. Use `try` e `except` para tratar erros de entrada e adicione uma mensagem personalizada para cada tipo de erro encontrado (exemplo: "Erro: Divisão por zero" ou "Erro: Entrada inválida").
